# Portafolio de Bryan Jiménez

Portafolio profesional orientado a desarrollo backend e ingeniería de datos, construido con Astro, TypeScript y Tailwind CSS.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Compilación

```bash
pnpm build
```

El sitio se publica automáticamente en GitHub Pages al enviar cambios a la rama `main`.
